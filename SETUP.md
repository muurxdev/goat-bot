# Instalação do GOAT

O guia completo de instalação (Windows, Linux e macOS, Termux, desenvolvimento local e VPS com Docker) está no [README.md](README.md).

Resumo:

```bash
npm install
cp .env.example .env
npm start        # mostra o QR code para login no WhatsApp
```

Requisito: Node.js 22.5 ou superior.
